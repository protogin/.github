# Support

Thanks for your interest in Protogin.

## Project status

Protogin is early-stage and most of our repositories are still private while
the product takes shape. There is no public product, ticketing system, or
paid-support channel yet.

## Getting help

- **Bugs or feature requests on a public repository:** open an issue in that
  repository using the provided issue templates.
- **Contribution questions:** see [CONTRIBUTING.md](CONTRIBUTING.md).
- **Security issues:** do **not** open a public issue. See
  [SECURITY.md](SECURITY.md) instead.

## What not to expect here

Please don't send account-specific, billing, or customer-support requests
through GitHub — this organization is for engineering and community
purposes only. There is no public support inbox at this stage; check back
as the project matures.
