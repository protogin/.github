# Protogin

Protogin builds modular business software — CRM, scheduling, invoicing, and
marketing tools that share a common platform instead of living in separate
silos.

We're early: most of our source code is still in private repositories while
the product takes shape. This organization hosts our public-facing project
information, community health files, and reusable CI workflow templates.

## Where to go

- **Found a security issue?** See [SECURITY.md](https://github.com/protogin/.github/blob/main/SECURITY.md).
- **Want to contribute to a public repository?** See [CONTRIBUTING.md](https://github.com/protogin/.github/blob/main/CONTRIBUTING.md).
- **Need help or have a question?** See [SUPPORT.md](https://github.com/protogin/.github/blob/main/SUPPORT.md).

## Community standards

Everyone interacting in Protogin repositories and communication channels is
expected to follow our [Code of Conduct](https://github.com/protogin/.github/blob/main/CODE_OF_CONDUCT.md).
